# Shubham Gupta — portfolio

A responsive, static portfolio based on Shubham's résumé. It uses plain HTML, CSS, and a tiny JavaScript file. There is no build step.

## Publish on GitHub Pages

1. Create a **public** GitHub repository named `shubhamgsg.github.io`.
2. Upload the **contents of this folder** to the root of the repository: `index.html`, `styles.css`, `script.js`, `favicon.svg`, and `Shubham_Gupta_SDET_Automation.pdf`. Commit the files to the `main` branch.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. When deployment completes, visit `https://shubhamgsg.github.io/`.

For an existing repository with another name, the same files can be deployed as a project site at `https://shubhamgsg.github.io/<repository-name>/`. The relative asset paths work there too.

## Before sharing

- Review the public résumé. It includes a phone number, while the webpage itself shows only an email and LinkedIn link.
- The project cards link to your public MovieBookingApplication and EventManagementAPI repositories.
- Update `index.html` when your role, skills, certification, or project details change.

## Local preview

Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000`.
